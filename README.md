# 🧩 cub

`cub` is a small but ambitious C project that focuses on low-level programming, maze logic, and game-engine fundamentals.

Think of it as a challenge in structure, precision, and problem solving: parsing, rendering, movement, and map-based logic all packed into one neat project.

## 🌟 Highlights

- Map parsing and validation
- Game loop architecture
- Grid-based world logic
- C-focused engineering mindset

## 🧪 Run it

```bash
make
./cub
```

## 🚀 Why it matters

It is a great example of turning a simple idea into a working system with careful planning, efficient logic, and strong debugging discipline.

> Minimal code, maximal brainpower.
